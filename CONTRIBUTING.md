# Contributing

For a bug report, include the theme name/version, section, reproduction steps,
expected behavior, actual behavior, and a screenshot if useful. Do not include
customer data, account credentials, or private store details.

For a change:
1. Explain the user problem in an issue or pull request.
2. Keep styles scoped to the section instance and avoid external dependencies.
3. Preserve keyboard operation and visible focus.
4. Follow docs/TESTING.md and report exactly what you tested.
5. Include only code or assets you can contribute under the MIT license.

Small substantive fixes are welcome. Please avoid generated bulk changes,
duplicate submissions, or contributions made only to inflate activity counts.
